# feiq-glm · 局域网文件互传

一个**零依赖**的局域网文件/文件夹互传 Web 应用，类似飞秋 / LocalSend 的网页版。
Mac 与 Windows 11 运行同一份代码，启动后自动发现同一局域网内的其他节点，在浏览器里拖拽即可把文件"推"到对方电脑上。

## 功能

- 🔍 **自动发现**：UDP 广播自动发现同网段节点，也可手动输入 `IP:端口` 添加
- 📂 **文件 / 文件夹互传**：支持多文件与整个文件夹，自动保留目录结构
- ✋ **手动确认接收**：对方发来文件时弹窗确认，接受后才开始传输
- 📊 **实时进度**：收发双端都有进度条与状态显示
- 💬 **文本消息**：节点之间可互发简短文字
- 🛠 **零依赖**：仅使用 Node.js 内置模块，无需 `npm install`

## 环境要求

- [Node.js](https://nodejs.org/) ≥ 16（Mac 与 Windows 都需要）
- 两台电脑处于同一局域网（同一网段）

## 启动

### macOS

```bash
# 方式一：双击 start.command（首次可在"系统设置 → 隐私与安全性"中放行）
# 方式二：终端运行
cd feiq-glm
node server.js
```

### Windows 11

```bat
:: 方式一：双击 start.bat
:: 方式二：命令行运行
cd feiq-glm
node server.js
```

启动后会打印本机的局域网访问地址（如 `http://192.168.1.5:3210`）并自动打开浏览器。
**两台电脑都启动后**，双方会出现在彼此的「局域网节点」列表里。

### 防火墙放行

- **macOS**：首次运行如弹出"是否允许 node 接收传入网络连接"，点「允许」
- **Windows**：首次运行如弹出 Windows 防火墙提示，勾选**「专用网络」**后点「允许访问」

## 使用

1. 在左侧节点列表点击要发送到的设备（在线状态为绿点）
2. 把**文件或文件夹**拖入发送区，或点「选择文件 / 选择文件夹」
3. 对方网页会弹出确认框，点「接受」后开始传输，进度实时可见
4. 接收的文件保存在对方电脑的 **`下载/feiq-glm/<发送者名>-<时间>/`** 目录（可在界面查看具体路径）
5. 下方输入框可与对方互发文本消息

> 提示：只在一台电脑上运行也可以——其他设备直接用浏览器打开 `http://<该机IP>:3210`，即可互传文件（经该机中转）。

## 配置

| 环境变量 | 说明 | 默认值 |
|---|---|---|
| `PORT` | HTTP 端口（被占用自动 +1） | `3210` |
| `UDP_PORT` | 发现协议起始 UDP 端口（共尝试 5 个） | `32101` |
| `NAME` | 本机设备名 | `主机名 (系统)` |
| `SAVE_DIR` | 接收文件保存目录 | `~/Downloads/feiq-glm` |
| `CONFIG_PATH` | 配置文件路径 | `./config.json` |
| `NO_OPEN` | 设为 `1` 不自动打开浏览器 | — |

设备名和保存目录也可直接在网页上修改（保存到 `config.json`）。

## 故障排查

| 问题 | 处理办法 |
|---|---|
| 看不到对方节点 | 确认两机在同一网段、防火墙已放行；部分 Wi-Fi 开了「AP 隔离 / 访客网络」会阻断互访，可改用热点或网线；也可手动输入对方 `IP:端口` 添加 |
| 手动添加也连不上 | 在对方机器浏览器里访问 `http://127.0.0.1:3210` 确认服务已启动；检查防火墙 |
| 端口被占用 | 启动日志会显示实际端口，或用 `PORT=8080 node server.js` 指定 |
| 接收目录想换位置 | 网页左上角只改名字；目录用 `SAVE_DIR` 环境变量或直接编辑 `config.json` |

## 安全说明

本应用面向**可信局域网**（家庭 / 办公室）设计，节点间通信未做加密与鉴权，请勿在公共网络中使用。

## 实现说明

- 服务端：Node.js 内置模块（`http` / `fs` / `dgram` / `os` / `crypto`），单文件 `server.js`
- 前端：原生 HTML / CSS / JS 单页，通过 SSE 实时接收节点上下线、传输请求、进度与消息
- 传输路径：发送方浏览器 **直连** 接收方服务端（不经第三方中转）
- 同一台机器运行多个实例做测试时，请为每个实例指定不同的 `CONFIG_PATH` 与 `PORT`
